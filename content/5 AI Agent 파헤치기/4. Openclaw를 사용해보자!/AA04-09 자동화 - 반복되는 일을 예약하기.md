## 자동화 — 반복되는 일을 예약하기

모니터링 절에서 지금 상태를 보는 눈을 얻었습니다. 이번에는 스스로 움직이는 시간표를 만듭니다. 반복되는 일을 사람이 기억하지 않도록 예약하는 기능이 automations(오토메이션, 자동화 작업)입니다.

automations는 Gateway에 들어 있는 스케줄러입니다. 모델 안에서 실행되는 기능이 아닙니다. Gateway 프로세스가 실행 중이어야 예약한 시간에 일이 시작됩니다.

일정, 실행 상태, 실행 기록은 OpenClaw의 공유 SQLite 데이터베이스에 저장됩니다. Gateway를 다시 시작해도 예약 자체가 사라지지 않습니다. 실행 결과는 채팅 채널, 웹훅 또는 기록으로 보낼 수 있습니다. ([docs.openclaw.ai/automation/cron-jobs](https://docs.openclaw.ai/automation/cron-jobs))

### 먼저 비어 있는 시간표를 봅니다

터미널에서 등록된 작업을 봅니다. 처음 사용하는 환경이면 목록은 비어 있습니다.

```bash
openclaw automations list
```

`openclaw automations`는 작업을 만들고, 목록과 상세 정보, 실행 기록을 보고, 지우는 명령입니다. 짧게 `openclaw cron`이라고 써도 같은 명령으로 동작합니다.

작업을 만들거나 지우거나 즉시 실행하는 변경 명령에는 `operator.admin` 권한이 필요합니다. 권한은 예약이 실행되는 조건과 별개로 먼저 확인합니다.

### 3분 뒤의 알림을 만듭니다

먼저 UTC의 현재 시각을 확인합니다. 출력된 시각에서 3분 뒤의 ISO 시각을 계산합니다.

```bash
date -u +%FT%TZ
```

아래 `<ISO시각>` 자리에 계산한 시각을 넣습니다. `--session main`은 앞에서 연 WebChat의 main 세션으로 시스템 이벤트를 보냅니다.

```bash
openclaw automations create "<ISO시각>" --name "첫 알림" --session main --system-event "3분 전에 예약한 알림이 도착했습니다"
```

일회성 예약은 시간이 되면 main 세션에 도착합니다. WebChat을 열어 그 메시지가 나타나는지 봅니다. 한 번만 실행하는 작업은 성공적으로 끝나면 자동으로 지워집니다.

작업을 만들 때는 일정이 먼저이고 프롬프트가 그 다음입니다. 위 명령은 프롬프트 대신 시스템 이벤트를 넣은 형태입니다. 이름은 목록에서 작업을 알아보기 쉽게 붙입니다.

### 5분마다 울리는 시보를 만듭니다

cron 표기식(분 시 일 월 요일)은 반복 시간을 다섯 칸으로 적는 방식입니다. `*/5 * * * *`에서 첫 칸 `*/5`는 5분마다를 뜻합니다. 나머지 네 칸의 `*`는 모든 시, 모든 날, 모든 달, 모든 요일을 뜻합니다.

```bash
openclaw automations create "*/5 * * * *" "지금 시각과 대기 중인 알림이 있으면 한 줄로 알려 줘" --name "5분 시보"
```

몇 분 기다리며 WebChat에 시보가 두 번 도착하는지 봅니다. 이 작업은 반복 일정이므로 한 번 실행되어도 목록에 남고 다음 5분을 기다립니다.

### 실행된 기록을 봅니다

`openclaw automations list`에서 시보의 작업 ID를 확인한 뒤, 그 작업의 실행 기록을 봅니다.

```bash
openclaw automations runs --id <job-id>
```

시보가 두 번 울렸다면 기록에도 두 번의 실행이 생깁니다. 일회성 작업은 실행 뒤 목록에서 사라지지만, 반복 작업은 다음 실행 시간을 가진 채 목록에 남습니다. 목록과 실행 기록을 나란히 보면 이 차이가 그대로 나타납니다.

Gateway를 끄면 스케줄러도 함께 멈춥니다. 그동안에는 예약 시간이 되어도 작업이 실행되지 않습니다. 다시 켠 뒤에도 SQLite에 저장한 일정과 이전 실행 기록은 남아 있습니다.

### 같은 일을 대화로 시킵니다

다섯 칸 표기식을 외우지 않아도 예약을 만들 수 있습니다. 대화로 시키는 길이 두 가지 있습니다.

첫째는 반복을 알아채는 길입니다. 같은 부탁을 여러 번 하면 에이전트가 먼저 예약으로 바꿀지 제안합니다. 만들기 전에 일정과 할 일을 사람의 말로 한 문장 확인합니다. "매주 평일 오전 7시에 어제 밤 업데이트를 요약해 이 방에 올립니다" 같은 문장입니다. 이 문장을 확인하면 예약이 만들어집니다. cron 표기식이 아니라 사람의 문장으로 확인하게 하는 설계입니다.

둘째는 대화 명령 `/loop`입니다. WebChat에서 `/loop 5m 지금 시각을 한 줄로 알려 줘`를 보내면 이 대화에 묶인 5분 반복 작업이 만들어집니다. 소유자만 쓸 수 있는 명령입니다. 간격을 빼면 1분에서 1시간 사이에서 스스로 다음 실행을 정합니다. `/loop status`로 이 대화의 반복 작업을 보고 `/loop stop`으로 끕니다.

WebChat에서 `/loop`로 시보를 하나 만들어 봅니다. 그다음 `openclaw automations list`를 다시 실행해 CLI로 만든 시보와 `/loop`로 만든 시보가 한 목록에 나타나는지 확인합니다. 만드는 입구가 달라도 스케줄러는 하나입니다.

### 실습이 끝나면 시간표를 비웁니다

`list`에서 5분 시보의 작업 ID를 찾습니다. 아래 명령의 `<job-id>`에 그 값을 넣어 작업을 지웁니다.

```bash
openclaw automations remove <job-id>
```

`/loop`로 만든 시보는 대화창에서 `/loop stop`으로도 지울 수 있습니다.

반복 작업을 남겨 두면 Gateway가 켜져 있는 동안 계속 실행됩니다. 실습이 끝난 작업은 지우는 습관이 필요합니다.

시간표를 만들었으니, 다음 절에서는 OpenClaw에 더 연결할 수 있는 기능들을 둘러봅니다.
