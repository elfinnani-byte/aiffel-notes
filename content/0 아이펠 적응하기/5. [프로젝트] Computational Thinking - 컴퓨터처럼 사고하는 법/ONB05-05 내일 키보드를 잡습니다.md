# [5.프로젝트 Computational Thinking - 컴퓨터처럼 사고하는 법] - 5. 내일 키보드를 잡습니다

---

## 과제 제출하기

- **제출물**: 자기 도메인 업무 분해 예시
- **학습 목표**: 본인의 도메인 전문성을 AI 서비스 관점에서 정리하고, 과정 전체에서 다룰 개인 문제를 초안으로 정의합니다.
- **제출 형식**: 마크다운 문서

### 자기 도메인 전달 형식 채우기

앞서 만든 마케터 형식을 자기 도메인으로 바꿔 메모장이나 노션에 적어 보세요. 빈칸 형식만 옮겨 둡니다.

```
[도메인 맥락]
나는 ____ 도메인 ____ 년 차이고, ____ 작업을 자동화/정리하고 싶습니다.

[네 동작 분석]
1. 분해: ____
2. 패턴: ____
3. 추상화: ____
4. 알고리즘: ____

[출력 요구]
____ 형식으로, 한국어로.

[검증 기준]
____ 한 사람이 ____ 라고 평가할 것.
```

> 🔍 **자기 점검**: 위 형식에서 한 칸이라도 비어 있다면, 그 칸은 "아직 내가 또렷하게 생각하지 못한 부분"입니다. 빈 칸 자체가 내일 무엇을 더 다듬어야 할지 알려 주는 신호입니다.

**자주 빠지는 칸 - 예시 답안**

가장 자주 비는 칸은 **[검증 기준]**입니다. "잘 작동하면 좋겠어"로 끝내면 AI가 자기 기준으로 만들어 검증이 어렵습니다. "누가", "어떤 기준으로" 합격을 판단하는지 미리 적으면 AI가 그 기준에 맞춰 결과를 만듭니다. 검증 기준은 도메인 전문가만 정할 수 있는 칸입니다.

## OT 모듈 3일을 한 줄로 잇기

3일 동안 손에 쥔 것을 한 자리에 모읍니다.

| Day | 손에 쥔 것 |
| :--- | :--- |
| Day 1 | 내 도메인 경력은 약점이 아니라 출발점 — 정체성·지도·함께 배우는 환경 |
| Day 2 | 막힘은 정상 신호 — 막힘을 연료로 바꾸는 내 루틴 |

### 출처 · 더 찾아보기

- **컴퓨팅 사고법(Computational Thinking)**: [Jeannette M. Wing (2006), "Computational Thinking," Communications of the ACM 49(3), 33–35](https://www.cs.cmu.edu/~15110-s13/Wing06-ct.pdf) — 이 용어를 대중화한 원 글.
- 분해 · 패턴 인식 · 추상화 · 알고리즘은 컴퓨터과학에서 오래 쓰여 온 일반 개념으로, 윙이 이를 '일상 사고의 도구'로 다시 정리한 것입니다.
- **사람·AI·조합 성능 비교(메타분석)**: [Michelle Vaccaro, Abdullah Almaatouq & Thomas Malone (2024), "When combinations of humans and AI are useful: a systematic review and meta-analysis," Nature Human Behaviour 8, 2293–2303](https://doi.org/10.1038/s41562-024-02024-1) — 사람 단독·AI 단독·사람+AI 조합 106개 실험을 종합. 조합의 이득은 사람이 AI보다 나은 과제에서 커진다.

### 핵심 정리

| 챕터 | 손에 쥐고 갈 것 |
| :--- | :--- |
| 1 | 핵심 한 문장 — 컴퓨팅 사고법 = 큰 문제를 AI가 풀 수 있는 작은 조각으로 나누는 사고법 |
| 2 | 하나의 사고법, 네 동작 — 분해·패턴 인식·추상화·알고리즘. 한 사이클로 오감 |
| 3 | 나는 이미 이 사고법을 쓰고 있다 + 컴퓨팅 사고법이 못 푸는 영역(창의·맥락·가치 판단)은 사람의 자리 |
| 4 | 내 도메인 문제 한 가지를 네 동작으로 쪼갠 한 페이지 + AI 전달 형식 초안 |
