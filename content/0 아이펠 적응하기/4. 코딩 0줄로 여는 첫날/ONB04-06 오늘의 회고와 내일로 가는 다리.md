## 오늘의 회고와 내일로 가는 다리

## 오늘의 회고

자기 노트에 세 줄을 적고 오늘을 닫습니다. 형식 없이 솔직하게. (앞서 본 주간 회고의 축소판이라고 생각하면 됩니다 — 매주 이 동작을 반복하게 됩니다.)

1. **머리** — 첫 챕터에서 적었던 두 줄, 특히 "AI가 대신 해주지 못할 내 분야의 일"이 지금은 어떻게 보이나요? 한 문장으로.
2. **손** — 오늘 ChatGPT의 답을 도메인 전문가의 눈으로 채점했습니다. 'X'나 '△'를 매겼던 칸 하나를 다시 적어보세요. 그게 오늘 여러분이 판단을 내린 증거입니다.
3. **마음** — 어제의 나보다 무엇이 한 가지라도 편해졌나요? ("내 경력이 약점이 아닐 수도 있겠다" 정도면 충분합니다.)

🤔 시작할 때 2번을 못 적었다면, 지금 다시 답해보세요. 세 가지 무기 중 하나는 적을 수 있을 것입니다.

### 핵심 정리

| 챕터 | 손에 쥐고 갈 것 |
| :--- | :--- |
| 1강 | 핵심 한 문장 — 도메인 전문성은 약점이 아니라 출발점이자 자산 |
| 2강 | 코딩으로 못 메우는 세 무기 — 문제 인식 · 판단 · 신뢰. 그중 판단을 직접 휘둘러봄 |
| 3강 | 넉 달 다섯 굽이 지도 + 지금 내 위치(출발선) |
| 4강 | 상생 · Learning by Doing · 주간 회고(KPT) · 디스코드 입장 |
| 5강 | 첫 AI 대화 + 도메인 평가 워크북 + 결과물 방향 2가지 |
| 6강 | 회고 세 줄 — 머리·손·마음의 변화 기록 |
