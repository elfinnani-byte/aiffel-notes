# [1.바이브코딩을 위한 작업대 마련하기] - 3. 첫 프로젝트 폴더와 파일 만들기

## 첫 프로젝트 폴더와 파일 만들기

```
첫 프로젝트: 폴더에서 파일까지

my-first-web
  └─ index.html
```

이제 작업대 위에 첫 산출물을 올립니다. 오늘 만들 것은 `my-first-web` 폴더와 `index.html` 파일입니다. 이 파일이 이후 첫 화면 제작의 출발점이 됩니다.

아래 명령은 프로젝트를 모아둘 위치에서 실행합니다. 예를 들어 문서 폴더 아래에 만들고 싶다면 먼저 `cd ~/Documents`로 이동합니다.

```bash
mkdir my-first-web
cd my-first-web
pwd
touch index.html
```

(Windows PowerShell: `New-Item index.html`, 또는 `ni index.html`)

`pwd`는 현재 위치를 보여줍니다. 이 출력은 나중에 AI에게 "내가 어느 폴더에서 작업 중인지" 설명할 때 단서가 됩니다.

### AI에게 첫 파일 생성을 맡기는 프롬프트

백지에서 HTML을 외워 쓰지 않습니다. 먼저 AI에게 만들 것을 말하고, 나온 결과를 읽고 판단합니다. 프로젝트 폴더(`my-first-web`)에서 Claude Code를 실행한 뒤 아래 요청을 입력합니다. Claude Code가 `index.html`을 직접 만들어 줍니다. 대괄호 안은 자기 도메인으로 바꿉니다.

> 프롬프트: "index.html 파일에 브라우저에서 바로 열 수 있는 첫 화면을 만들어줘.
> 조건:
> - 한국어 문서로 설정해줘.
> - 큰 제목에는 [내 이름 또는 역할]을 넣어줘.
> - 본문에는 [내 도메인]에서 AI를 활용해 보고 싶은 일을 한 문장으로 넣어줘."

이 요청은 코드를 대신 써 달라는 요청이지만, 책임까지 넘기는 요청은 아닙니다. 다음으로 AI가 낸 결과 예시를 읽고 검토합니다.

```html
<!-- AI가 생성한 결과 예시입니다. 그대로 외워 쓰는 코드가 아니라 검토 대상입니다. -->
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>나의 첫 웹페이지</title>
</head>
<body>
  <h1>교육 운영 전문가 김아이펠</h1>
  <p>교육 현장에서 반복되는 안내 업무에 AI를 활용해 보고 싶습니다.</p>
</body>
</html>
```

### AI 출력 검토

위 예시는 동작할 수 있는 HTML입니다. 하지만 바이브 코딩에서는 "돌아간다"에서 멈추지 않고, 내 목표에 맞는지 확인합니다.

| 검토 질문 | 내 판단 |
| :--- | :--- |
| 제목이 내 역할이나 도메인을 드러내는가 | ____ |
| 본문 문장이 너무 넓거나 추상적이지 않은가 | ____ |
| 브라우저에서 열었을 때 글자가 보이는가 | ____ |

**검토 포인트 예시**

- `lang="ko"`, `meta charset="UTF-8"`이 있으면 한국어 표시 문제를 줄일 수 있습니다.
- 제목과 문장은 자기 도메인으로 바뀌어야 합니다. 예시 이름을 그대로 두면 산출물 증거가 약합니다.

### 산출물 체크

브라우저에서 `index.html`을 엽니다. 파일을 더블클릭해도 되고, 브라우저 주소창에 파일 경로를 넣어도 됩니다.

| 산출물 | 확인 |
| :--- | :--- |
| `my-first-web` 폴더가 있다 | ____ |
| `index.html` 파일이 있다 | ____ |
| 브라우저에서 제목과 본문이 보인다 | ____ |
| 내 도메인 문장으로 바꿨다 | ____ |
