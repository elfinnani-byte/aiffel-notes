# [1.바이브코딩을 위한 작업대 마련하기] - 6. 터미널로 폴더를 탐험하고 만들기

## 실습 1 - 터미널로 폴더를 탐험하고 만들기

### 안전한 연습 폴더에서 시작하기

> **안전 규칙**: 아래 명령은 삭제 명령을 쓰지 않습니다. 처음에는 바탕화면의 실제 파일 대신 `terminal-practice` 연습 폴더에서 실행하세요. 공백이 있는 이름은 따옴표로 감쌉니다.

| 명령 | 하는 일 |
| :--- | :--- |
| `pwd` | 지금 내가 있는 폴더의 전체 경로를 출력합니다. |
| `ls` | 현재 폴더 안의 파일·폴더 이름을 보여 줍니다. |
| `cd 폴더이름` | 지정한 폴더로 이동합니다. `cd ..`는 한 단계 위로 갑니다. |
| `mkdir 폴더이름` | 새 폴더를 만듭니다. |
| `touch 파일이름` | 빈 파일을 만들거나, 기존 파일의 수정 시각을 갱신합니다. |
| `rm 파일이름` | 기존 파일을 삭제합니다. |
| `mv 원본 대상` | 파일·폴더를 이동하거나 이름을 바꿉니다. 실행 전 원본과 대상을 꼭 읽습니다. |

> 🪟 **Windows PowerShell 사용자**: `pwd`, `ls`, `cd`, `mkdir`, `mv`는 PowerShell에서도 같은 이름으로 동작합니다. 두 가지만 다릅니다 — `touch`가 없으므로 `ni 파일이름`(New-Item)을 쓰고, 폴더 여러 개를 한 번에 만들 때는 `mkdir ideas, assets, archive`처럼 쉼표로 구분합니다.

**1단계 — 내 위치를 보고 연습 공간 만들기**

```bash
pwd
ls
mkdir terminal-practice
cd terminal-practice
mkdir ideas assets archive
ls
```

`pwd` 출력에서 현재 위치를 노트에 적고, `ls`로 `ideas`, `assets`, `archive` 세 폴더가 보이는지 확인합니다. 이미 "File exists"가 나오면 같은 이름의 폴더가 있다는 뜻이므로 `ls`로 확인하고 다음 단계로 갑니다.

**2단계 — 파일을 만들고 이동하기**

```bash
touch ideas/landing-page.txt
mkdir assets/images
mv ideas/landing-page.txt assets/images/landing-page.txt
ls assets/images
cd ..
pwd
```

(Windows PowerShell: `touch` 대신 `ni ideas/landing-page.txt`)

여기서는 빈 메모 파일을 만든 뒤 이미지 폴더로 옮겼습니다. `mv` 뒤의 `ls assets/images` 출력에 `landing-page.txt`가 보일 때만 성공입니다. **명령을 친 사실이 아니라 출력으로 확인**합니다.

**3단계 — 길을 잃었을 때 돌아오기**

```bash
cd terminal-practice
cd assets
pwd
cd ..
ls
```

`cd ..`는 "상위 폴더"로 가는 명령입니다. 화면에 보이는 이름만 믿지 말고, 이동할 때마다 `pwd`와 `ls`를 번갈아 사용하세요.

> **멈춤 신호**: 현재 위치가 불안하면 `pwd`부터 실행합니다. `mv`는 대상 경로를 한 글자씩 확인한 뒤 실행하며, 실제 중요한 파일에는 연습이 끝날 때까지 적용하지 않습니다.
