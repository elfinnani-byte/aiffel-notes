# [5.[프로젝트] 이미지 생성 어플리케이션 만들기] - 8. [과제] 원하는 포즈로 만들기

## 원하는 포즈로 만들기

지금까지 한 장 만드는 것까지 해 봤습니다. 마지막 과제는 한 발 더 나갑니다. 앞서 본 ControlNet의 포즈(Pose) 조건을 써서 **"이 자세로 한 장 만들어 줘"라는 도구를 직접 만드는 것**입니다. 산출물은 Colab 튜토리얼 노트 한 권이고, 그 노트를 GitHub에 올려 링크로 제출합니다.

튜토리얼 노트는 강사가 미리 만들어 주지 않습니다. 여러분이 직접 짭니다. 다만 빈 노트에서 시작하라는 뜻은 아니고, 앞서 본 [FLUX.2-klein 4B로 마음껏 이미지 만들기, Google Colab 노트](https://colab.research.google.com/drive/1axPf8sqixd2uksu-6_ZMFdpuU_fWfEPS?usp=sharing)를 출발점으로 삼아 거기에 포즈 조건을 얹는 방향으로 갑니다.

### 1단계, 포즈 조건을 넣어 도구를 만듭니다 (30~60분)

가장 단순한 버전은 이렇습니다. 참조로 쓸 사람 사진 한 장을 고르고, 그 사진에서 OpenPose가 사람 관절을 뽑게 합니다. 그 관절 정보를 ControlNet용 전처리로 넣고, 프롬프트와 함께 FLUX.2-klein 4B 또는 비슷한 모델에 넣습니다. 결과는 참조 사진과 **같은 자세**를 한 다른 인물이나 장면이어야 합니다.

여러분이 만드는 튜토리얼 노트에는 이 과정이 처음 보는 사람도 따라 할 수 있게 한 셀 한 셀 적혀 있어야 합니다. 셀마다 주석으로 '이 셀이 하는 일'을 적어 두십시오. 모델 로드, 포즈 추출, 이미지 생성, 결과 저장 각각을 한 셀로 나누면 보기 좋습니다.

### 2단계, 다른 포즈와 프롬프트로 바꿔 봅니다 (15분)

도구가 한 번 돌아갔다면, 이제 **조건을 바꿔 보며 잘 되는지 확인**합니다. 같은 포즈에 프롬프트만 바꿔 보고, 반대로 같은 프롬프트에 다른 포즈 사진을 넣어 봅니다. 어느 쪽을 바꿨을 때 결과가 크게 달라지는지, 어느 쪽은 잘 안 따라오는지 관찰합니다. 이 관찰이 노트의 마지막 마크다운 셀에 '무엇을 바꿔 보았고, 어떻게 달라졌는가'로 적혀 있어야 합니다.

### GitHub 제출용 폴더 구조

```

├── README.md          # 도구 설명, 사용법 한 줄

├── samples/           # 테스트 결과 예시

│   └── output_02.png

```

### 3단계, GitHub에 노트를 올리고 URL을 제출합니다 (5분)

위 폴더를 GitHub public 저장소에 올린 뒤, 저장소 URL 한 줄을 과제 제출란에 붙입니다.

GitHub 계정이 없으면 github.com에서 가입하십시오. 로그인한 뒤 오른쪽 위 `+` 메뉴에서 'New repository'를 고르고, 이름을 `pose-image-tool`로 정하고 Public으로 만듭니다. 그 다음 'uploading an existing file' 링크를 따라 폴더 안의 파일을 브라우저에 끌어다 놓으면 됩니다. 명령줄을 칠 필요가 없습니다. `.ipynb` 파일은 GitHub가 자동으로 노트 모양으로 보여 주어 클릭만 해도 코드가 보입니다.

업로드가 끝나면 저장소 주소가 `https://github.com/본인아이디/pose-image-tool` 형태로 나옵니다. 이 주소 한 줄이 제출물입니다.
