## 중간을 남겨야 되짚을 수 있습니다

### 이 다음은 어디로 가나

지금은 영상과 소리와 그림과 글을 **한 좌표계에 함께 올리는** 쪽으로 연구가 이어지고 있습니다. 앞에서 그림과 문장을 같은 공간에 놓는 이야기를 했는데, 거기에 영상과 소리까지 올리는 것입니다. 멀티모달이 대화 모델에만 걸린 이야기가 아니라는 뜻입니다. 검색, 추천, 유사 사례 탐색, 아카이브 구축에서도 모달리티 통합이 중요해집니다.

실제 업무로 옮기면 이런 질문이 생깁니다.

- "이 회의 녹음과 비슷한 결론이 나온 과거 문서는 무엇인가요?"
- "이 제품 사진과 비슷한 불량 사례의 상담 녹취는 무엇인가요?"
- "이 교육 영상에서 학생이 막힌 순간과 비슷한 풀이 노트는 무엇인가요?"

검색의 단위가 키워드에서 경험 단서로 확장되는 셈입니다.

### 오늘의 산출물 점검

아래가 남아 있으면 오늘의 학습은 끝난 것이 아니라, 다음 실습으로 넘어갈 준비가 된 것입니다.

| 산출물 | 완료 기준 | 내 상태 |
| :--- | :--- | :--- |
| 노션 회의록 페이지 | 확인이 필요한 곳에 녹취 시각이 남아 있고, 어느 설정으로 만든 회의록인지 적혀 있습니다. | |
| **회의록 실습 기록표** | 쓴 음성과 손으로 받아 적은 정답, 설정을 바꿔 가며 잰 기록, 가장 크게 좋아진 것과 오히려 나빠진 것, 견딜 수 있는 오류율과 근거, 요약본만 보고는 못 잡았던 오류, 노션 페이지 링크가 채워졌습니다. | |

아래 줄이 오늘 가장 오래 붙잡은 것입니다. **직접 돌려 보고 얻은 숫자**라서, 여러분 업무에 이 자동화를 붙일 수 있는지를 여기서 판단하게 됩니다.

### 핵심 정리

| 오늘 배운 것 | 한 문장 정리 | 실무 판단 |
| :--- | :--- | :--- |
| 모달리티 | 정보가 들어오는 감각·형식입니다. | 업무 증거가 어떤 형태로 존재하는지 먼저 봅니다. |
| VLM | 이미지와 언어를 같은 작업 안에서 연결합니다. | 사진 설명보다 근거 위치와 불확실성을 요구합니다. |
| 음성 통합 | STT/TTS를 넘어 말투, 침묵, 배경음, 실시간 대화가 들어옵니다. | 감정·의도 추정은 단정하지 않습니다. |
| 단일 모델 vs 파이프라인 | 통합 모델은 맥락 연결에 강하고, 전문 모델 조합은 검증에 강합니다. | 책임·비용·감사 로그 기준으로 고릅니다. |
| 멀티모달 위험 | 입력이 많을수록 결론이 더 그럴듯해 보입니다. | 근거의 원본 위치를 함께 내게 하고, 마지막 판단은 사람이 합니다. |
| 소리와 글자의 어긋남 | 소리는 이어져 흐르고 글자는 끊어집니다. 그 정렬을 누가 맞추느냐가 이 분야의 역사였습니다. | 지금 도구가 스텝을 어떻게 자르는지 보면 화자 분리가 붙을지 알 수 있습니다. |
| 한국어와 모델 크기 | 크기보다 그 언어를 봤느냐가 먼저입니다. 한국어로 다시 학습한 작은 모델이 훨씬 큰 모델에 붙습니다. | 영어 예제의 모델 크기를 그대로 쓰지 않습니다. |
| 지표의 단위 | 같은 결과가 글자 기준이냐 단어 기준이냐에 따라 네 배 차이로 보입니다. | 정확도 숫자를 들으면 무엇을 몇 번 재서 나온 값인지 묻습니다. |
| 목소리 합성과 복제 | 한국어로 노트북에서 도는 합성기는 있지만, **목소리를 고르는 것과 복제하는 것은 다른 기능**입니다. | 복제가 필요하면 그래픽카드와 라이선스와 목소리 주인의 동의를 먼저 확인합니다. |
| 실행 도구 | 같은 모델이라도 **무엇으로 돌리느냐에 따라 넣을 수 있는 입력과 속도가 달라집니다.** | 모델 카드만 보고 계획을 세우지 않고 내 환경에서 되는지 따로 확인합니다. |
| 요약의 세탁 | 받아쓰기 오류는 눈에 띄지만 요약을 거친 오류는 눈에 안 띕니다. | 의심스러운 곳을 다듬지 말고 원문 그대로 표시하게 시킵니다. |
