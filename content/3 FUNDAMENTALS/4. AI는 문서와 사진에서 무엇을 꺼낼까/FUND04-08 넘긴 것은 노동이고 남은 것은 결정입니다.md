## 넘긴 것은 노동이고 남은 것은 결정입니다

오늘 우리는 각 OCR, 객체탐지 도구가 어디에서 왔고 어떤 기술을 이어받았는지부터 따라갔습니다.

Tesseract는 특징 기반 OCR에서 LSTM 행 인식으로 발전한 로컬 엔진이고, PaddleOCR은 탐지·방향 판별·인식을 조립하는 PaddlePaddle 기반 도구 상자였습니다. PaddleOCR-VL은 문서 구조를 복원하려는 VLM이고, Claude·ChatGPT는 더 넓은 질문을 받는 범용 멀티모달 제품이었습니다.

사진에서는 최초 YOLO 공동 연구와 Darknet, 이후 갈라진 계보, 그리고 실습에 사용한 Ultralytics YOLO가 서로 다른 주체의 공헌임을 구분했습니다. 동시에 박스·마스크·관절점이라는 출력 차이와 Redmon이 제기한 군사·사생활 문제를 실제 사용 카드로 연결했습니다.

중요한 것은 도구의 유명세가 아니라 **만든 주체, 입력, 출력 자료형, 검증 방법, 실패와 사회적 영향이 서로 연결되어 있다는 사실**입니다.

### 핵심 정리

| 도구 | 답의 자료형 | 근거를 되짚는 방법 | 대표 실패 | 사람이 정할 것 |
| :--- | :--- | :--- | :--- | :--- |
| Tesseract·PaddleOCR | 문자열·점수·좌표 | 원본 위 좌표와 중간 결과 | 누락·오인식·잘못된 읽기 순서 | 인식 언어·언어별 가중치, 허용 오류, 재검수 조건 |
| PaddleOCR-VL | Markdown·표·수식·구조 | 원문 페이지와 원시 출력 대조 | 구조 누락·재배열·생성 | 파이프라인 버전, 추정 금지 규칙 |
| Claude·ChatGPT | 질문에 따른 문장·구조 | 원문 인용 위치와 대화 기록 | 환각·비공개 전처리·서비스 변경 | 업로드 가능 자료, 모델·실행일 |
| Detection | 클래스·박스·점수 | 정답 박스와 IoU, 원본 시각화 | 미탐·오탐·위치 오차 | 임계값과 놓치면 안 되는 대상 |
| Instance segmentation | 개체별 마스크 | 정답 마스크와 IoU·Dice·경계 지표 | 경계 누락·개체 합침 | 경계 기준과 면적 사용 조건 |
| Pose estimation | 사람별 keypoint | 기준 관절점과 원본 시각화 | 가림·관절 혼동·비인간 대상 무출력 | 자세 정의와 사람 검토 조건 |

각 도구의 출처와 개발 주체를 밝힌 뒤, 실제 결과에서는 **어떤 답을 주는지, 무엇과 대조할 수 있는지, 실패했을 때 누가 결정하는지**를 기록합니다. 오늘은 추론만 실행했고, 학습은 반복되는 도메인 실패와 권리가 확인된 라벨 데이터가 있을 때 검토합니다.

시작할 때 적은 세 칸을 다시 펴세요. 지금 답을 옆에 한 번 더 쓰고, 바뀐 답 하나에는 '무엇을 알고 나서 바뀌었는지'를 덧붙입니다.

처음 떠올린 문서와 사진을 다시 봅시다.

이제 "AI로 읽어 주세요"라고 한 덩어리로 넘기기 전에 질문을 나눌 수 있습니다. 글자와 좌표가 필요하면 OCR 엔진, 표와 수식의 구조가 중요하면 문서 파서·문서 VLM, 열린 질문을 빠르게 시험하려면 범용 VLM, 위치와 경계와 자세가 필요하면 각각 탐지·분할·포즈 가중치를 고릅니다.

코딩 에이전트에게는 설치와 연결, 반복 실행, 파일 저장과 UI 조립을 맡길 수 있습니다. 하지만 같은 입력을 썼는지, 모델을 몰래 바꾸지 않았는지, 결과가 원문 어디에서 왔는지, 틀리면 누가 확인할지는 사람이 정해야 합니다.

그래서 오늘의 결론은 도구 선택으로 끝나지 않습니다. 읽고 보는 노동은 위임할 수 있지만 **그 결과를 믿기로 한 결정은 위임되지 않습니다.** 이번 실습에서 남긴 원본 해시, 모델·버전, 원시 결과, `[UNCLEAR]`와 실패 기록이 그 결정을 감당하는 최소한의 근거입니다.

### 다음 시간에는

오늘 다룬 능력들은 성격이 하나로 묶입니다. 전부 파일 안에 이미 들어 있는 것을 찾아내는 일이었습니다. 글자를 읽어 내고, 상자를 그려 짚어 주고, 픽셀을 칠해 경계를 선언하는 일 모두 원본 어딘가를 가리킵니다. 원본에 대조할 근거가 남아 있고, 박스와 마스크처럼 별도 주석이 필요한 답도 사람이 합의한 기준으로 정답지를 만들어 평가할 수 있었습니다.

다음 시간에는 이 구조가 깨지는 자리로 갑니다. 원본에 없던 픽셀을 만들어 내는 쪽입니다. 직접 대조할 원본 정답이 없으면 맞았다 틀렸다를 따지는 방식 자체가 달라지고, 우리가 던져야 할 질문도 바뀝니다. 오늘 손에 익힌 검수 습관 중 무엇이 그대로 쓰이고 무엇이 통하지 않을지를 미리 한 줄 적어 두고 오시면, 다음 시간이 훨씬 빨리 갑니다.
