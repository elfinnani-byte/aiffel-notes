


# AIFFEL_7.[프로젝트] 공간을 다루는 AI

#### 학습목표
사진(영상)이 3차원→2차원으로 눌리면서 버려지는 "거리" 정보를 계산으로 되찾아, 자기 방을 웹에서 마우스로 돌려볼 수 있는 3D 결과물(가우시안 스플랫)로 만들어 개인 주소(GitHub Pages)에 올리는 것. 오늘은 코드를 직접 짜지 않고 코딩 에이전트에게 시키고 결과를 판단하는 눈을 기르는 것이 진짜 목표.

#### 학습내용
3차원을 담는 그릇 넷(메시/포인트클라우드/복셀/가우시안 스플랫)의 차이와, "화소에서 광선을 쏴 신경망에 묻는" NeRF(2020)에서 "알갱이를 화면에 눌러 찍어 겹쳐 바르는" 3D 가우시안 스플래팅(2023)으로 계산 방향이 뒤집힌 이유를 익히고, 스플랫 알갱이 하나가 위치·불투명도·크기·회전·구면조화 등 실수 62개(248바이트)로 이루어진다는 것을 파악한다.

폰으로 방을 걸어 다니며 찍은 영상 한 편에서, 시차(가까운 것은 많이 밀리고 먼 것은 조금 밀리는 어긋남) 원리로 거리를 되찾는 MapAnything 모델을 Colab에서 돌려 색을 가진 3차원 점 300만 개와 카메라 위치 24개를 얻는다. 이 점이 스플랫 62개 값 중 근거가 있는 값(위치·색)만 채워주므로, 나머지 근거 없는 값(불투명도·크기·회전)은 시그모이드 역변환·반지름 공식 같은 규칙을 세워 직접 채워 넣어 가우시안 스플랫 파일(.ply)로 완성하는 법을 배운다.

이렇게 만든 217MB짜리 파일은 GitHub Pages(100MiB 제한)에 못 올라가므로 .sog 형식으로 14배 압축하고, three.js와 Spark 렌더러로 마우스·터치로 돌려볼 수 있는 정적 웹페이지를 만들어 개인 주소에 배포하는 전 과정을 손으로 겪는다.

동시에 이 결과물의 한계(카메라가 안 지나간 곳은 검은 얼룩으로 남는다는 것, PSNR·SSIM·LPIPS로도 그 빈 곳은 잴 수 없다는 것)를 이해하고, 오늘 쓴 방식이 SfM·MVS·SLAM·NeRF를 거쳐 지금의 피드포워드 복원(DUSt3R→VGGT→MapAnything)에 이르기까지 서로 무엇을 막고 무엇을 대신 내주며 이어져 왔는지를 훑는다. 마지막으로 오늘 쓴 도구들의 라이선스를 직접 확인해, 이 분야에서 가장 유명한 원본 3D Gaussian Splatting 구현조차 상업적으로는 못 쓴다는 것처럼 "유명한 것과 쓸 수 있는 것은 다르다"는 판단 습관까지 갖춘다.

**“사진은 2차원인데, 어떻게 사진 속 공간을 3차원으로 되살릴 수 있을까?”**

### 1. 「셔터가 닫힐 때 사라지는 것」

#### 핵심은 딱 하나입니다.

**사진을 찍는 순간 3차원 공간의 ‘거리’가 사라진다**는 것입니다.

실제 방에는
- 컵 → 30cm
- 모니터 → 1m
- 벽 → 3m

처럼 각각 다른 거리가 있습니다.
그런데 사진으로 찍으면 각 픽셀에는 기본적으로 **RGB 색 정보**가 남습니다.

즉,

> **3차원 → 2차원으로 바뀌면서 깊이(거리) 정보가 사라진다.**

파일에서는 이것을 “버려진 거리를 되찾는 것”이라고 표현합니다. 

#### 그렇다면 왜 3D가 필요한가?

사진 여러 장만으로는 물체의 뒤쪽이나 옆쪽을 제대로 알기 어렵습니다.
하지만 공간을 3D로 되살리면

> **사진 여러 장 → 하나의 돌려볼 수 있는 3D 공간**

이 됩니다.
그래서 부동산, 상품 소개, 수리 매뉴얼 같은 곳에서 활용할 수 있습니다.

___
### 2. 배우는 전체 과정

앞으로 할 프로젝트를 **4단계**로 정리합니다.

> **찍는다 → 점이 된다 → 알갱이가 된다 → 줄여서 올린다** 

이것이 이번 프로젝트의 가장 중요한 흐름입니다.

**① 찍는다** : 스마트폰으로 방을 촬영합니다.
**② 점이 된다** : 사진에서 3차원 위치를 계산하여 **3D 점(Point Cloud)** 으로 만듭니다.
**③ 알갱이가 된다** : 점은 크기가 없기 때문에 그대로는 보기 좋지 않습니다.
그래서 점에 **`크기`, `투명도`, `방향`** 등을 부여해서 **3D Gaussian Splat**으로 만듭니다.
**④ 줄여서 올린다** : 만든 3D 데이터를 웹에서 볼 수 있을 정도로 압축하고 웹 주소에 올립니다.


### 3. 「무엇에 담고 무엇이라 부르나」

파일 01에서 전체 여행 경로를 봤다면, 파일 02는 **“3D 공간을 컴퓨터에 어떻게 표현할 것인가?”**를 공부합니다.

3차원을 표현하는 방법은 하나가 아닙니다.

파일에서는 대표적으로 4가지를 비교합니다.|방식|쉽게 말하면|
|방식|쉽게 말하면|
|**Mesh**|삼각형으로 표면을 만든다|
|**Point Cloud**|점들의 모음으로 표현한다|
|**Voxel**|공간을 작은 칸으로 나눈다|
|**3D Gaussian Splatting**|퍼지는 반투명 알갱이로 표현한다|


# 4. 네 가지를 아주 쉽게 이해하면

### 🟦 Mesh

점을 찍고 **`점 ─ 점 ─ 점`** 이것들을 삼각형으로 연결합니다.
그래서 물체의 **표면**을 만드는 방식입니다.
게임, 3D 프린팅 등에 많이 사용됩니다.

---

### 🟢 Point Cloud

말 그대로 **점들의 구름**입니다. 예를 들어 방을 측정해서

> ● ● ● ● ● ● ● ●

이렇게 수백만 개의 점으로 표현합니다.
문제는 **점에는 크기가 없다는 것**입니다.

그래서 가까이 확대하면

> ● ● ●

사이에 빈 공간이 생깁니다.
파일에서는 이 때문에 포인트 클라우드를 그대로 화면에 사용하기 어렵다고 설명합니다. 

---

### 🟨 Voxel

3차원 공간을 작은 상자들로 나눕니다.  쉽게 말하면 **3D 픽셀**입니다.

```
▣ ▣ ▣
▣ ■ ▣
▣ ▣ ▣
```

픽셀이 2차원이라면 복셀은 3차원입니다.
특히 공간의 **속까지 표현**할 수 있다는 장점이 있습니다. 

---

### 🟣 3D Gaussian Splatting

이번 프로젝트의 주인공입니다.

포인트 클라우드의

> ●

점 하나를

> ◉

처럼 **크기와 투명도를 가진 부드러운 알갱이**로 바꿉니다.

그리고 수백만 개의 알갱이를 서로 겹쳐 놓습니다.

그러면 점 사이의 빈 공간이 사라지고 **하나의 표면처럼 보이게 됩니다.**

파일에서는 이것을

> **“점에 부피와 투명도를 붙인 것”**

이라고 설명합니다. 

---

# 5. 그런데 왜 굳이 Gaussian Splatting인가?

여기가 파일 02의 중요한 부분입니다.

기존의 3D 방식에서는 **표면을 만들어야 하는 경우**가 많습니다.

예를 들어 Mesh라면

> 점 → 점 → 점 → 삼각형 → 표면

을 만들어야 합니다.

그런데 사진으로부터 얻은 점들은

> “여기까지가 벽이고, 여기부터가 책상이다.”

같은 **정확한 표면 경계가 명확하지 않을 수 있습니다.**

Gaussian Splatting은 굳이 표면을 삼각형으로 만들지 않습니다.

그냥

> **점 + 크기 + 투명도 + 방향**

등을 가진 알갱이를 겹쳐서 화면을 만듭니다.

그래서 사진에서 복원한 공간을 **사진처럼 자연스럽게 보여주는 데 적합**합니다. 

---

# 6. 파일 02에서 또 하나 중요한 개념: NeRF

파일 02는 여기서 한 단계 더 들어갑니다.

2020년경에는 **NeRF**라는 방식이 등장합니다.

NeRF는 공간을 삼각형이나 점으로 직접 저장하는 대신,

> **신경망에게 공간을 기억하게 하는 방식**

이라고 생각하면 쉽습니다.

공간의 위치와 바라보는 방향을 신경망에 넣으면,

> “그 위치를 이 방향에서 봤을 때 어떤 색이고 얼마나 불투명한가?”

를 신경망이 알려줍니다.

그래서 새로운 시점에서 이미지를 만들어낼 수 있습니다.

이 작업을

> **Novel View Synthesis  
> 새 시점 합성**

이라고 부릅니다. 

---

# 7. 그런데 NeRF의 문제가 생깁니다

NeRF는 품질은 좋지만 **계산량이 많습니다.**

한 장의 화면을 만들 때 수많은 위치에 대해 신경망에게 계속 질문해야 하기 때문입니다.

즉,

> 카메라 이동  
> ↓  
> 수많은 광선 계산  
> ↓  
> 수많은 신경망 호출  
> ↓  
> 화면 생성

이 과정이 반복됩니다.

그래서 **실시간으로 방을 돌려보는 것**에는 부담이 있습니다. 

그리고 여기에서 Gaussian Splatting으로 이어지는 흐름이 나옵니다.

# 8. 두 파일을 연결하면 이렇게 됩니다

전체 개념을 하나의 그림처럼 생각하면 쉽습니다.

```
📷 스마트폰으로 방 촬영
          ↓
      사진에는
      거리 정보가 없음
          ↓
    여러 사진의 차이
       = 시차
          ↓
   3차원 위치를 계산
          ↓
     ● ● ● ● ●
     Point Cloud
          ↓
 점에 크기 + 투명도 부여
          ↓
   ◉ ◉ ◉ ◉ ◉
  3D Gaussian Splat
          ↓
      웹에서 렌더링
          ↓
     🏠 3D 방 완성
```

파일 01은 **“왜 이 프로젝트를 하는가 + 전체 과정”**이고,

파일 02는 그중에서도 특히

> **“3차원 공간을 어떤 데이터 구조로 표현할 것인가?”**

를 설명합니다.

## ⭐ 지금 단계에서 꼭 기억할 5개

AI로 공간을 다루는 공부를 시작한다면 우선 이것만 확실히 잡으면 됩니다.

**① 사진**  
→ 3차원 공간을 2차원으로 눌러버린 것

**② 시차(Parallax)**  
→ 카메라 위치가 달라졌을 때 같은 물체가 다르게 보이는 현상  
→ 이것을 이용해서 거리를 추정할 수 있음

**③ Point Cloud**  
→ 3차원 공간을 수많은 점으로 표현

**④ 3D Gaussian Splatting**  
→ 점에 크기·투명도 등을 부여해서 부드러운 알갱이로 표현

**⑤ Novel View Synthesis**  
→ 실제로 찍지 않은 새로운 시점의 화면을 만들어내는 것

특히 **① → ② → ③ → ④ → ⑤**의 관계를 이해하면, 앞으로 나올 파일 03~05도 훨씬 쉽게 이해할 수 있습니다.
