## 공짜로 세상에 올리기 - 무료 서버 고르기

앞에서 "배포"를 배웠죠. 그럼 자연스러운 질문 — **돈 안 들이고 올릴 수 있나요?** 네, 됩니다. 요즘은 비전공자가 만든 웹앱을 **무료로** 인터넷에 띄울 수 있는 곳이 여럿입니다.

다만 한 가지 재미있는 흐름을 먼저 알아 두면 좋습니다. **공짜의 세계는 계속 줄어드는 중**입니다.

- **Heroku** — 한때 초보들의 성지였던 무료 서버가 **2022년 11월 완전히 사라졌습니다.**
- **Railway** — 2023년, **Fly.io** — 2024년에 상시 무료를 없앴습니다.
- **Glitch** — 2025년 7월 앱 호스팅을 종료했습니다.

왜일까요? 무료 계정을 **암호화폐 채굴** 같은 곳에 악용하는 사람이 늘면서, 회사들이 공짜를 거둬들인 겁니다. (출처: Heroku 공식 FAQ; Railway Blog) 그러니 **"지금 무료인 것도 언젠가 바뀔 수 있다"** 는 전제로, 아래 목록도 **가입 직전에 공식 요금 페이지를 한 번 확인**하는 습관이 안전합니다.

### 지금 쓸 만한 무료 호스팅 (2026년 기준 · 정책은 바뀔 수 있음)

무엇을 올리느냐에 따라 고르면 됩니다. 용어 두 개만 미리 — **정적 사이트**는 화면만 있는 것(포트폴리오·소개 페이지), **백엔드**는 뒤에서 데이터를 처리하는 부분입니다.

| 서비스 | 뭘 올리기 좋나 | 무료로 주는 것 · 주의점 | 카드 |
| :--- | :--- | :--- | :--- |
| **Cloudflare Pages** | 정적·프론트 | **대역폭 무제한** - 트래픽 걱정이 가장 적음 | 불필요 |
| **GitHub Pages** | 정적 전용 | 가장 단순. 코드 저장하던 곳에 그대로 게시 | 불필요 |
| **Vercel (Hobby)** | 프론트·Next.js | 손이 가장 덜 감. 단 **개인·비상업용만 허용** | 불필요 |
| **Netlify** | 정적·프론트 | Vercel 대안, **상업적 이용 허용** | 불필요 |
| **Render** | 백엔드 API | **15분 안 쓰면 잠듦**(다시 깨는 데 ~1분) | 불필요 |
| **Supabase** | 백엔드+DB | DB·로그인 한 번에. **7일 미사용 시 일시정지**(데이터는 보존, 아주 오래 방치하면 삭제될 수 있음) | 불필요 |
| **Oracle Always Free** | 진짜 리눅스 서버(VM) | 상시 무료 VM을 줌. 단 **카드 필요·설정 어려움** | 필요 |

표의 한도·정책은 각 서비스 공식 요금 페이지에서 최신으로 확인하세요. (출처: 각 사 공식 문서 - Vercel/Netlify/Cloudflare/Render/Supabase/Oracle, 2026)

### 이럴 땐 이걸로 시작

고민되면 아래 기본값으로 시작하면 됩니다.

- **포트폴리오·소개 페이지(화면만)** → Cloudflare Pages 또는 GitHub Pages
- **프레임워크로 만든 프론트(Next.js 등)** → Vercel(수익 내는 서비스라면 나중에 유료로)
- **로그인·저장이 필요한 백엔드+DB** → Supabase가 무난한 1순위. API 서버가 따로 필요하면 Render를 곁들이기
- **"진짜 서버를 만져 보며 공부"하고 싶다** → Oracle Always Free(단, 설정 난이도가 있음)

이 선택도 결국 **AI에게 물어보면** 됩니다. "내가 만든 건 이런 서비스인데, 무료로 올리기 좋은 곳과 그 제약을 표로 알려줘"라고요. 여러분은 답을 **판단**하면 됩니다 — 이 강의가 그 판단의 밑감입니다.

### 무료 티어, 시작 전에 알아 둘 세 가지 함정

공짜라고 방심하면 뒤통수를 맞는 지점들이 있습니다.

- **잠듦(spin-down)** — 무료 백엔드는 한동안 아무도 안 오면 **잠듭니다.** 오랜만의 첫 방문자는 화면이 뜨는 데 1분쯤 걸릴 수 있어요(고장 아님). Render 무료가 대표적입니다.
- **기한·일시정지** — 무료 DB가 **일정 기간 뒤 사라지거나**(예: Render 무료 Postgres는 30일 후 만료), **안 쓰면 잠시 멈추는**(예: Supabase 7일) 경우가 있습니다. **중요한 데이터는 백업**을 꼭 따로 받아 두세요.
- **요금 폭탄 방지** — 카드가 걸린 서비스(클라우드 VM 등)는 **예산 알림·상한**을 걸어 두세요. 트래픽이 튀거나 실수로 큰 자원을 켜면 청구서가 나올 수 있습니다.

정리하면 — **무료는 "배우고 시연하기"엔 충분**합니다. "많은 사람에게 안정적으로 24시간 제공"하는 단계가 오면, 그때 유료를 검토하면 됩니다.
