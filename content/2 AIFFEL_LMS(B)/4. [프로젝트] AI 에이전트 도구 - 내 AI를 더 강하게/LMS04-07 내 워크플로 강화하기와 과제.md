## 범용 AI를 '내 전용 조수'로 - 워크플로 강화하기

### 내일 아침의 장면으로 다시 보기

내일 팀원이 "어제 만든 예약 화면에서 오늘 예약만 보여 줘"라고 합니다. 이때 범용 채팅창에 화면 구조·DB 이름·확인 순서를 매번 길게 설명하면, 일은 되더라도 같은 설명을 계속 반복하게 됩니다. 오늘 배운 것은 그 반복을 줄이는 방법입니다.

**하네스** 를 하나 고르고(내 조건에 맞게),

**MCP나 앱의 CLI** 로 내 데이터·도구에 잇고(규칙 파일로 사용법을 알려 주고),

자주 하는 일을 **스킬** 로 외워 두면 -

범용 AI가 **내 서비스를 아는 전용 조수** 로 바뀝니다. 단, 조수에게 권한을 준다고 검토 책임까지 넘기는 것은 아닙니다. 처음에는 읽기 전용 연결과 작은 작업부터 시작하고, 실행 결과를 내가 확인하는 습관을 남겨 둡시다.

### 과제 - 내가 실제로 쓸 스킬 하나, GitHub에 올리기

오늘 배운 개념이 내 것이 되려면 직접 하나 만들어 봐야 합니다. **내가 매번 AI에게 반복해서 시키던 일** 을 스킬 하나로 만들어, 남이 봐도 쓸 수 있게 GitHub에 올리세요. 제출은 **저장소 링크 하나** 입니다.

**1. 스킬 후보 고르기**

"AI한테 또 이걸 설명하고 있네" 싶은 순간이 후보입니다. 예:

- 코드를 고칠 때마다 우리 팀 린트·컨벤션을 다시 알려 주는 일
- 작업을 끝내고 항상 돌리는 정리 (커밋 메시지·변경 요약)
- 회의록·안내문을 우리 팀 양식으로 바꾸는 일

**2. 저장소를 만들고 스킬 쓰기**

새 GitHub 저장소를 하나 만듭니다 (예: `my-skills`). 그 안에 스킬 폴더와 `SKILL.md`를 만듭니다. Claude Code 기준 경로는 `.claude/skills/<스킬이름>/SKILL.md`이고, 다른 도구는 각 도구의 스킬 위치에 둡니다. 파일은 프론트매터(`name`·`description`)와 본문으로 씁니다.

```
---
name: commit-summary
description: 오늘 작업을 우리 팀 커밋 메시지 양식으로 요약할 때 사용
---

# 커밋 메시지 요약

1. `git diff`로 바뀐 부분을 확인한다.
2. 바뀐 것을 주제별로 묶어 한 줄씩 요약한다.
3. 양식은 `[범위] 한 일 (#이슈)` 로 맞춘다.
```

**3. README로 '왜' 쓰기**

저장소 최상단 `README.md`에 **왜 이 스킬을 만들었는지** 를 한 장으로 씁니다. "무슨 불편이 있었고, 스킬이 어떻게 없앴는지"가 한눈에 들어와야 합니다.

**4. 올리고 링크 제출**

push하고 저장소 링크를 제출합니다. 보너스로 친구에게 링크를 주고 "이 스킬 써 봐" 했을 때, 따로 설명하지 않아도 돌아가면 성공입니다.

**제출 전 체크**

- 스킬이 '매번 반복하던 일'에서 나왔는가? (스킬의 본질)
- `description`만 봐도 언제 쓰는지 아는가?
- README에 '왜'가 불편에서 해결로 적혀 있는가?
- 다른 대화에서 한마디로 발동시켜 보았는가?

### 오늘의 회고

자기 노트에 짧게 남겨 보세요.

- MCP를 'USB-C'에 빗댄다면, 내 서비스에서 가장 먼저 꽂고 싶은 것은?
- 내가 매번 반복해서 설명하던 일(=스킬 후보)은 무엇인가?
- 새 AI 도구가 쏟아질 때, 나를 덜 휩쓸리게 해 줄 기준 하나는?

### 핵심 정리

| 오늘 배운 것 | 한 문장 정리 | 내가 할 수 있는 행동 |
| :--- | :--- | :--- |
| 에이전트의 구조 | 에이전트 = 모델(지능) + 하네스(껍데기)입니다 | 도구를 볼 때 '하네스'를 봅니다 |
| MCP | AI를 내 데이터·도구에 꽂는 'USB-C' 표준입니다 | 연결하고 싶은 데이터를 하나 고릅니다 |
| 스킬 | 반복 작업을 외워 두는 재사용 설명서입니다 | 매번 반복하던 지시를 스킬 후보로 적습니다 |
| 규칙 파일 | 프로젝트 상시 안내문(AGENTS.md·CLAUDE.md)입니다 | 반복 설명을 파일에 한 번 적어 둡니다 |
| CLI로 잇기 | 앱 명령을 규칙 파일로 알려 두면 AI가 직접 실행합니다 | 자주 쓰는 조회를 명령 하나로 만듭니다 |
| 도구 선택 | 종류는 많고 빠르게 바뀌니 '내 조건'으로 고릅니다 | 개념을 잡고, 유행에 덜 휩쓸립니다 |
