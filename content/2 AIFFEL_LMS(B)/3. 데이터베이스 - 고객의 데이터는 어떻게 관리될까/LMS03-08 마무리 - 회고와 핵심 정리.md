### 핵심 정리

| 오늘 배운 것 | 한 문장 정리 | 내가 할 수 있는 행동 |
| :--- | :--- | :--- |
| 데이터베이스의 역할 | 서비스의 '기억' - 데이터를 남기고 빠르게 찾아 줍니다 | 새로고침해도 남아야 할 데이터를 구분합니다 |
| 역사와 갈래 | 파일→SQL→NoSQL(4종)→클라우드로 발전했습니다 | 표(SQL)와 유연한 상자(NoSQL)의 성격을 압니다 |
| SQL 알아보기 | SQL은 거의 영어 문장이며, 코드는 AI가 씁니다 | `SELECT … FROM … WHERE …`를 말로 풀 수 있습니다 |
| 보안·백업 | SQL 주입은 파라미터화로 막고, 데이터는 백업으로 지킵니다 | AI에게 '파라미터화·해시·자동 백업'을 요구합니다 |
| 무료 DB 고르기 | 무료 티어로 시작하되 한도·백업·정책을 압니다 | 첫 서비스엔 Supabase(Postgres)를 후보로 둡니다 |
